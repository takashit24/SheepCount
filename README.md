# 新春！ひつじを数えろ！2027

ビルドも外部サービスも不要な、日本語の観察力ミニゲームです。2027年の未年をテーマに、Canvasで牧場と羊を描きます。素材のダウンロードは不要です。

## 起動・公開

`index.html` をブラウザで開くだけで遊べます。開発時は以下がおすすめです。

```sh
cd /workspace/SheepCount
python3 -m http.server 8000
```

ローカルでポート8000を開いてください。GitHub Pagesではファイル一式をリポジトリにコミットし、Settings → Pages → Deploy from a branchで公開ブランチのルートを選択します。すべて相対パスなのでサブディレクトリ公開に対応します。サーバー・データベース・npmインストールは不要です。

## 遊び方

3、2、1、STARTの後に60秒間観察します。左から右へ成功なら+1、ぶつかって戻れば0、右から左へ脱走したら-1。右側の牧場内は初め0匹。最後に牧場内にいる羊の頭数を答えます。終了時は新規登場と未登場の予約を取り消し、動いている羊が全て移動を終えるまで待ちます。正解は大当たり、誤差2匹以内はおしい、それ以外は残念。音は初期OFFです。ONにすると内蔵の短い合成効果音を鳴らします。

タブを隠している間はタイマーとアニメーションが止まります。復帰時に経過時間を飛ばしません。

## 構成・調整

- `config.js`: 時間、初期頭数、序盤・中盤・終盤の出現間隔（秒）、連続数、通常/失敗/脱走の重み。
- `engine.js`: 羊ごとのID・状態・時間、出現予約、右側の在籍リスト、シード乱数。各羊のジャンプ終了＝着地時に一度だけ加減算します。失敗は羊の体全体が柵の手前に留まる軌道です。
- `app.js`: 画面遷移、Canvas描画、音、回答検証。羊は最大3レーンで、同じレーンは1匹まで。2〜4匹の連続登場が混み合った場合は空きレーンを待ちます。
- `style.css`: モバイル・PC共通のUI。

脱走では、右側に待機している実在の羊IDを先に予約してから動かします。成功して右へ退出中の羊は、待機に入ってから脱走対象になります。同時に同じIDが動くことはありません。待機中の羊は小屋の中にいるものとして描画しません。羊が柵を越えてから小屋の方へ進み、脱走する羊は小屋の方向から現れます。柵は奥から手前へ斜めに伸び、羊は各レーンでその柵を越えます。

再現するには `?seed=42` のように数値シードをURLに付けます。同じシードで再プレイしても同じ乱数列を使います（時間刻みが違う端末では出現時刻にフレーム単位の差があります）。

## 素材の差し替え

`config.js` の `assets` に自作・利用許諾済み素材の相対パスを設定します。

- `sheep`: 右向きの透過画像。90×65の領域に描画し、左向き時は反転。
- `background`: 900×580を基準に牧場全体へ描画。柵と羊は前面へ重なります。
- `jump` / `fail` / `escape`: 効果音ファイル。空欄なら合成音。音声ON操作後のみ再生。
- `results.exact` / `close` / `miss`: 結果別のお祝い画像。空欄なら絵文字とメッセージ。

動画演出を追加する場合は `app.js` の `result()` を入口にし、iOS向けに `playsinline` とユーザー操作に基づく再生を使ってください。標準版は動画を読み込まないため軽量です。

## 検証

追加インストールなしでエンジンのテストを実行できます（Node.js 18以上）。

```sh
node --test tests/engine.test.cjs
```

成功/失敗/脱走の計上、失敗の軌道、逆向き移動、同時計算、重複防止、脱走の在籍制約、終了後の完了待ち、100シードの保存則とリセットを検証します。

実機iPhone Safariの確認は別途必要です。Web AudioはSafariの接頭辞付きAPIにも対応し、Canvasと標準DOMを使用しています。回答欄は0以上の整数を受け付け、全角数字も半角に変換して判定します。
